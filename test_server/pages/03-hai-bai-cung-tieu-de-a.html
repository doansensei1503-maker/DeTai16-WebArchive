Bài viết A: Hướng dẫn cài đặt Ubuntu Server

Tác giả: Lê Văn B · Ngày đăng: 05/03/2024

Trong bài viết này chúng ta sẽ tìm hiểu cách cài đặt Ubuntu Server 22.04 từ đầu đến cuối một cách chi tiết. Việc cài đặt hệ điều hành server là bước đầu tiên quan trọng nhất khi bạn muốn triển khai một hệ thống web hoặc ứng dụng trên môi trường thực tế.

Trước khi bắt đầu, bạn cần chuẩn bị một máy tính hoặc máy ảo có ít nhất 2GB RAM, 20GB đĩa cứng trở lên và một đĩa USB khởi tạo. Bạn cũng cần có kết nối Internet ổn định để tải về các gói cài đặt trong quá trình thực hiện các bước sau đây.

Chuẩn bị đĩa cài đặt

Trước hết, ta tải file ISO của Ubuntu Server 22.04 LTS từ trang chính thức của Canonical. File ISO này có dung lượng khoảng 2GB, nên bạn cần lưu trong ổ đĩa USB. Sau đó sử dụng công cụ Rufus để ghi file ISO này lên USB.

Trước khi ghi, hãy chọn chế độ UEFI trong Rufus nếu máy chủ của bạn hỗ trợ UEFI. Chế độ Legacy sẽ được sử dụng cho máy chủ cũ hơn và không hỗ trợ UEFI.

Quy trình cài đặt

Khi đã ghi xong file ISO lên đĩa USB, ta khởi động lại máy tính và chọn boot từ đĩa USB. Màn hình cài đặt sẽ hiện lên, tại đây ta chọn ngôn ngữ là Tiếng Việt và cấu hình máy chủ theo hướng dẫn của trình cài đặt.

Bạn có thể chọn kiểu phân vùng thủ công để tùy biến phân vùng đĩa, hoặc chọn phân vùng tự động để đơn giản nhất. Với người mới bắt đầu, phân vùng tự động là lựa chọn an toàn và tiết kiệm thời gian nhất.

Thiết lập cấu hình sau khi cài đặt

Sau khi cài đặt xong và hệ thống đã khởi động lại, bạn cần cấu hình một số thông số cơ bản. Trước hết là cập nhật hệ thống qua lệnh apt update && apt upgrade. Tiếp theo là tạo một tài khoản không phải root để sử dụng hằng ngày và thay đổi quyền root.

Bạn cũng nên cài đặt và cấu hình firewall bằng ufw để bảo vệ máy chủ khỏi các kết nối không mong muốn từ bên ngoài. Cuối cùng, hãy thiết lập dịch vụ SSH để có thể quản lý máy chủ từ xa một cách thuận tiện.
